Ekstensi Chrome

↓ Unduh ekstensi Chrome

Gunakan Chrome biasa untuk memutar film, melewati iklan, dan menyelesaikan verifikasi. Ekstensi mendeteksi playlist tanpa Inspect Element.

Pemasangan paling mudah: melalui Chrome Web Store dengan tombol Add to Chrome. Ekstensi ini belum diterbitkan di Store, sehingga paket ZIP saat ini dipasang sekali melalui Load unpacked. File .crx mandiri bukan pengganti pemasangan Store pada Chrome biasa di Mac/Windows. Setelah terpasang, ekstensi tetap tersedia; tidak perlu Load unpacked setiap kali digunakan.

1. Pasang ekstensi pertama kali
  1. Klik Unduh ekstensi Chrome di atas.
  2. Buka folder Downloads dan klik dua kali ZIP untuk mengekstraknya.
  3. Buka Chrome, ketik chrome://extensions di bilah alamat, lalu Enter.
  4. Aktifkan Developer mode / Mode developer di kanan atas.
  5. Klik Load unpacked / Muat yang belum dipaketkan.
  6. Pilih folder chrome-extension hasil ekstrak yang berisi manifest.json, bukan file ZIP atau folder induknya.
  7. Klik ikon puzzle di toolbar Chrome, lalu pin OmniFetch Companion. Ikonnya merah–hitam dengan panah download.
  8. Muat ulang tab film yang sudah terbuka agar panel ekstensi aktif.
2. Hubungkan ekstensi ke aplikasi
  1. Jalankan Mulai.command dari folder aplikasi. Biarkan Terminal terbuka.
  2. Salin alamat aplikasi di bilah browser ini: .
  3. Klik ikon ekstensi → Pengaturan ekstensi, atau gunakan tombol pengaturan pada panel di halaman film.
  4. Tempel alamat tersebut lalu klik Simpan pengaturan.
  5. Jika aplikasi dijalankan ulang dengan port berbeda, perbarui alamat pengaturan. Copy link JSON tidak membutuhkan alamat aplikasi.
3. Deteksi video dan subtitle di Chrome
  1. Buka halaman film pada situs yang didukung. Selesaikan CAPTCHA sendiri jika muncul.
  2. Klik Play, tunggu iklan selesai atau gunakan tombol Skip yang disediakan situs.
  3. Pastikan yang sedang berjalan adalah film, bukan iklan.
  4. Aktifkan subtitle Bahasa Indonesia pada pemutar agar permintaan subtitle muncul.
  5. Panel OmniFetch muncul di pojok kanan bawah ketika config playlist terdeteksi.
  6. Ekstensi memprioritaskan config-….json terbaru. Nama file saja belum menjamin sumbernya film. Jika salah, gunakan Ganti sumber atau Bersihkan hasil iklan dari popup toolbar, lalu putar film kembali.
4. Copy link, preview, atau kirim ke Downloader
  1. Copy link JSON menyalin URL lengkap beserta token. Tempel di kolom utama aplikasi jika ingin mengirim secara manual.
  2. Kirim ke Downloader membuka aplikasi dengan URL video, judul, dan subtitle dari sumber yang sama jika terdeteksi. Ini belum memulai unduhan.
  3. Di popup toolbar, gunakan Preview isi playlist / JSON untuk membaca respons. Playlist utama berisi #EXTM3U dan #EXT-X-STREAM-INF; pilihan resolusi akan ditampilkan.
  4. Preview meminta ulang respons dan dapat ditolak server meskipun pemutar berjalan. Token disamarkan di preview.
  5. Pengaturan sumber lain, subtitle tambahan, dan tombol perbarui daftar tetap tersedia di popup toolbar.
5. Mulai unduh dan susunan folder
  1. Periksa Nama file. Nama ini juga dipakai untuk membuat folder film.
  2. Pilih kualitas terbaik, maksimal 720p, atau maksimal 480p.
  3. Pilih folder utama, misalnya Downloads. Aplikasi otomatis membuat subfolder film di dalamnya.
  4. Contoh: Downloads/Onslaught (2026)/Onslaught (2026).mp4 dan Onslaught (2026).srt dalam folder yang sama. Karakter nama yang tidak didukung akan dibersihkan.
  5. Klik Mulai unduh. Status, kecepatan, estimasi waktu, dan garis laser menunjukkan aktivitas.
  6. VTT otomatis dikonversi menjadi SRT UTF-8. Subtitle utama dan film memiliki nama persis sama, hanya ekstensinya berbeda.
  7. Jika ada beberapa subtitle berbeda, subtitle tambahan diberi penanda bahasa/nomor agar tidak menimpa subtitle utama.
  8. Jika film lengkap sudah ada, unduhan video baru memakai folder bernomor. File lama tetap tersimpan.
6. Subtitle saja dan pemutaran di media player
  1. Pilih tab Subtitle saja atau Kirim subtitle saja di ekstensi.
  2. Gunakan nama film dan folder utama yang sama untuk menyimpan SRT ke folder film yang sesuai.
  3. Jika video ada di folder bernomor atau lokasi lama, pindahkan SRT ke sebelah video dan samakan nama dasarnya.
  4. Buka MP4 dengan media player. Jika subtitle tidak muncul otomatis, gunakan menu Subtitle → Add/Load subtitle, lalu pilih SRT.
  5. SRT berisi nomor urut, waktu seperti 00:00:01,000 --> 00:00:04,500, teks, dan baris kosong. Tampilan/font khusus VTT bisa berubah saat konversi.
7. Hentikan, lanjutkan, dan analisis masalah
  1. Klik Hentikan unduhan untuk membatalkan. File sementara dapat digunakan untuk melanjutkan.
  2. Untuk melanjutkan video yang belum selesai, gunakan nama film, folder utama, dan kualitas yang sama. Gunakan tautan baru jika token lama kedaluwarsa.
  3. Kecepatan nol atau progres diam bisa berarti server sedang menunggu/timeout. Aplikasi menunggu hingga 60 detik pada operasi koneksi dan mencoba ulang hingga 5 kali.
  4. HTTP 403 berarti akses ditolak. Putar ulang film, salin URL baru, dan isi alamat halaman asal bila diperlukan. CAPTCHA tetap diselesaikan di browser.
  5. Subtitle gagal tidak selalu menggagalkan unduhan video. Periksa Detail proses.
  6. Klik Salin status & log lalu tempel untuk analisis. Laporan menyertakan URL lengkap dan token sumber proses.
  7. Jika Program terputus, jalankan Mulai.command dan perbarui alamat aplikasi di pengaturan ekstensi.
8. Memperbarui ekstensi dan batas dukungan
  1. Unduh ZIP terbaru, ekstrak, lalu ganti isi folder ekstensi yang dipasang dengan versi baru.
  2. Buka chrome://extensions dan klik Reload ⟳ pada OmniFetch Companion.
  3. Muat ulang halaman film. Jika folder dipindah, gunakan Load unpacked pada lokasi baru dan hapus versi duplikat.
  4. Ekstensi saat ini mendukung situs pemutar yang tercantum pada manifest ekstensi. Domain pemutar lain mungkin tidak terdeteksi.
  5. Ekstensi tidak melewati CAPTCHA dan tidak mengambil cookie login. Beberapa sumber tetap dapat menolak downloader.
  6. Menutup panel dengan × menyembunyikannya sampai halaman dimuat ulang. Popup toolbar tetap bisa digunakan.
