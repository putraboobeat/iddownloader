OMNIFETCH COMPANION v2.0.3 — PANDUAN PENGGUNAAN

SERVER PERMANEN
Ekstensi OmniFetch Companion kini terhubung secara permanen ke server produksi:
https://dw.pmlab.id
Pengguna tidak perlu lagi mengisi atau menyetel alamat server manual.

PASANG / PEMBARUAN EKSTENSI
1. Buka Google Chrome dan buka chrome://extensions di bilah alamat.
2. Aktifkan Developer mode / Mode developer di pojok kanan atas.
3. Klik tombol Update (atau Reload pada kartu OmniFetch Companion jika sudah terpasang).
   Jika baru pertama kali memasang, klik Load unpacked / Muat yang belum dipaketkan,
   lalu pilih folder "chrome-extension".
4. Muat ulang (Refresh / F5) tab halaman streaming atau media yang sedang dibuka.

AUTENTIKASI & TOKEN SESI (X-App-Session)
1. Ekstensi menggunakan header autentikasi X-App-Session untuk memisahkan antrean
   dan riwayat unduhan masing-masing pengguna.
2. Buka Pengaturan Ekstensi (klik kanan ikon ekstensi -> Options atau tombol ⚙️ di popup):
   - Masukkan token sesi Anda dari web dashboard dw.pmlab.id, ATAU
   - Tekan tombol "🔑 Buat Otomatis" untuk menghasilkan token sesi baru seketika.
3. Klik "Simpan Pengaturan". Anda dapat menguji status sesi dengan tombol "Uji Koneksi Sesi".

CARA MENGUNDUH MEDIA STREAMING (HLS / DASH / MP4)
1. Buka halaman film / video di situs yang Anda tuju (misal Idlix atau pemutar streaming).
2. Putar video (Play). Jika ada iklan, tunggu atau lewati iklan hingga video utama berputar.
3. Buka popup OmniFetch Companion:
   - Sumber streaming yang tertangkap akan diberi label jelas:
     [Playlist HLS], [Manifest DASH], atau [Video langsung].
   - Respons non-media seperti token claim, analitik, dan tracking otomatis disaring keluar.
   - Respons unverified (.json) yang belum terbukti sebagai media akan menonaktifkan tombol
     unduh demi mencegah pengiriman URL yang salah.
4. Pilih sumber video dan subtitle (bila ada).
5. Klik "⬇ Kirim Playlist ke Server".
   - Ekstensi akan menampilkan progres pengiriman ke dw.pmlab.id.
   - Setelah server menerima tugas, status "Pekerjaan Diterima Server" dengan Job ID
     dan tautan langsung ke Dashboard akan ditampilkan.

CARA MENGUNDUH SOSIAL MEDIA LANGSUNG (YouTube, IG, TikTok, X)
1. Buka halaman video YouTube, Reel Instagram, atau TikTok.
2. Klik popup OmniFetch Companion -> Klik "🚀 Sedot ke dw.pmlab.id".
3. Tugas otomatis dikirimkan ke server downloader.

PESAN ERROR DAN SOLUSINYA
- "Sesi belum terhubung atau kedaluwarsa": Buka Pengaturan dan pastikan token sesi sudah diisi.
- "Tidak dapat terhubung ke server": Periksa koneksi internet Anda ke dw.pmlab.id.
- "Waktu koneksi habis (timeout)": Server sedang sibuk; jangan mengirim ulang berulang kali.
- "Sumber media tidak valid": Sumber yang dipilih bukan stream yang dapat diproses server.
- "Pekerjaan ditolak server": Server menolak permintaan (periksa log atau batasan server).
